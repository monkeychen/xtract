# Xtract PRD - v0.2.0 (自动化巡检与生态联动规划路线图)

> **版本标识**：v0.2.0 (Roadmap)  
> **规划周期**：2026 Q4 ~ 2027 Q1  
> **状态**：⏳ 规划中  
> **前置版本**：[v0.1.0.md](v0.1.0.md)

---

## 1. 演进愿景
让 Xtract 从一个「被动唤起使用的桌面工作台」，升级为「能够自主感知前沿动态、主动沉淀个人知识库、并在多平台间无缝流转的私有情报雷达中枢」。

---

## 2. 规划特性矩阵 (Planned Features)

### 2.1 本地向量知识库 (Local RAG & Semantic Radar)
- **业务需求**：随着本地归档的 Page Bundle 推文与万字 X Article 专栏达到数千篇，传统的关键词匹配无法满足深层概念与灵感联想诉求；
- **规划规格**：
  - 基于本地轻量嵌入模型或主流 Embedding API，对已抓取的长推文与专栏正文进行分块与向量化存储；
  - 提供语义搜索与灵感唤醒面板，支持按概念寻找相似讨论（例如输入“自注意力机制优化”，自动关联历史沉淀的全部相关博主推文）；
  - 基于本地向量库直接向大模型提问（Chat with Tweets）。

### 2.2 后台自动化巡检与系统原生通知 (Daemon Radar)
- **业务需求**：用户不需要时时刻刻打开应用盯着，重要情报能自动按预设周期巡检并提醒；
- **规划规格**：
  - 支持配置巡检定时计划（如每 4 小时、每日早晨 8 点）；
  - 静默后台拉取关注流与核心博主动态；
  - 遇到高爆高赞（如 500+ 赞、1000+ 转发）或核心博主发长文时，通过 macOS 系统原生通知进行低打扰提醒。

### 2.3 创作成稿流水线与多平台生态联动
- **Astro 静态博客一键同步**：
  - 支持将精选的高价值专栏与长推文，一键导出为符合 Astro Content Collections 规范的 Markdown 文章并部署发布；
- **微信百宝箱 (wx-kit) 素材打通**：
  - 与本地微信文章文库打通，推特一手爆款情报可直接作为公众号或墨问笔记的创作选题素材，实现“推特外网雷达 -> 微信内网输出”的高效闭环。
