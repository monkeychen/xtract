## 1. 产品定位与核心价值

**Xtract** 是一款面向专业技术人员、新媒体创作者与投研分析师的 **高信噪比 X (Twitter) 实时情报雷达与 AI 结构化研报系统**。

产品采用纯 Node.js / Electron（TypeScript）单运行时架构，同一二进制支持双模驱动：
- **GUI 桌面工作台**：收敛于唯一核心视窗「XTRACT 情报工作台」，提供四维情报聚合、长文沉浸式阅读、免落盘视频流式播放与全局设置中心；
- **Headless CLI**：面向终端极客与下游 Agent 管道，标准 JSON 输出，支持自动化流水线编排。

## 4. 已取消与废弃功能详细说明 (Cancelled & Deprecated Rationale)

遵照第一性原理，以下功能在历史迭代中经业务验证后被果断废弃，**严禁后续 AI 或开发人员擅自重新引入**：

1. ❌ **GUI 二级 Tab（「趋势雷达」与「智能研报」）**：
   - **取消原因**：早期从“功能完备性”出发设计了二级 Tab，但实际使用中，用户在桌面端的核心心智是“沉浸式阅读与精选内参”，在多个 Tab 间反复横跳造成了严重的体验割裂与认知负担；
   - **对用户的影响**：砍掉后，工作台只有唯一视窗「XTRACT 情报工作台」，操作路径极大缩短；趋势研报能力移交至 CLI 自动化管道（`--trends-digest`），各得其所。
2. ❌ **推文切换时静默视频探测 (`preload="metadata"`)**：
   - **取消原因**：会静默向推特视频 CDN 发起 HEAD/Range 探测，遭遇代理延迟会触发 Chromium 缓冲转圈，无故消耗梯子流量并造成视觉卡顿；
   - **对用户的影响**：改为 `preload="none"`，未点击播放前零流量消耗、零转圈。
3. ❌ **单推抓取默认捕获作者追评/Thread**：
   - **取消原因**：推特大部分长推文只需要看首发主帖，旧逻辑默认全量拉取追评，导致推文列表充斥同作者连续短推文、单篇抓取等待耗时增加数倍、导出的 Markdown 产生多余章节；
   - **对用户的影响**：收敛为默认关闭，用户与终端脚本可按需显式开启。
