## 1. CLI 快捷方式（真机验收驱动修复）

v0.1.0 的快捷方式在真实安装环境暴露两个缺陷，本版修复：

1. **macOS 入口由符号链接改为 bash shim**（`exec` 指向应用内真实可执行文件）：
   - 缺陷实录：软链启动时 Electron 按软链所在目录（`~/bin/`）定位 Helper.app，CLI 每次调用刷屏 `FATAL: Unable to find helper app` 与 GPU/network service 错误；
   - **旧链接自动迁移**：设置中再次点击「创建命令行快捷方式」，检测到指向正确的旧软链时静默升级为 shim，无需手动删除；
2. **`-v` 短别名**：`xtract -v` 与 `--version` 等效（此前 `-v` 报 unknown option，commander 默认仅提供 `-V`）。

## 2. 抓取统计契约（诚实反馈）

同一列表两次抓取的完成提示谎报「入库 13 条」（实为 13 条全部主键去重跳过），引发用户对数据丢失的误判。

- **统一返回契约 `FetchAndStoreResult`**：`fetchUserAndStore` / `fetchListAndStore` / `fetchSearchAndStore` 统一返回 `{ tweets, fetched, inserted, skipped }`（真实落库统计），IPC 透传，覆盖修复「user/list 源把拉取数冒充新增数、skipped 写死 0、list 源返回裸数组」的契约断裂；
- **完成提示必须如实**：toast 与进度卡片只允许使用真实数字（如「拉取 15 条，新增入库 0 条，跳过重复 15 条」），严禁用拉取数冒充新增数；
- **X 列表滚动按捕获量驱动**：废弃固定轮数滚动（慢加载列表 limit=50 实得 15 条），改为按实际捕获的 GraphQL 批次推进——批次达目标页数停、连续 3 屏无新增（列表到底）提前停、轮数硬上限兜底（`shouldScrollListTimeline` 纯函数）；
- **语义澄清**：抓取条数选择是**上限**而非保证，列表内容不足时以实际可得为准。

## 3. 工作台交互一致性

- **四维源顺序**：关注流 → 博主追踪 → X 列表 → 全网搜索（三个个人订阅源聚拢，全网搜索收尾）；
- **四源抓取按钮完全统一**：默认「🔄 抓取最新 N 条」（N 实时跟随条数选择），抓取中「⏳ 正在抓取...」，替换原「搜索抓取」「抓取推文」等各源自拟文案；
- **操作区布局统一**：各源均为「输入/选择控件在前、抓取按钮在后」，输入框样式同源（13px、min-width 160px、自适应撑满），placeholder 统一 🔍 图标；
- **删除「已存 N 篇」提示**：该数字是全库计数，放在列表语境下被误读为列表存量；
- **a11y**：InfoTip 改为 `span[role=button]`（HTML 禁止 button 嵌套，此前嵌在 cta-button 内触发浏览器告警），保留完整键盘支持。

## 4. 发布管线（工程基建）

- **Windows 安装包**：NSIS（x64），`better-sqlite3` 直用官方 prebuilds（`npmRebuild: false`，node-gyp 不支持交叉编译）；
- **双平台 CI**：tag 触发 GitHub Actions 矩阵（macos-latest + windows-latest），每平台跑全量测试 → tsc → 构建 → electron-builder → 打包 smoke，产物自动汇聚 GitHub Release；公有仓库免费；
- **E2E 属地化**：GUI E2E 依赖真实本地 Vite+Chrome+代理，仅在本地执行（CI 自动排除），CI 为纯单元/集成门禁；
- **本地打包命令**：`pnpm pack:mac` / `pack:win` / `pack:all` / `pack:dir`（详见 `docs/operations.md` §10）。
