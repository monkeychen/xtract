## 1. 目标与定位
构建极简、工业级、无外挂依赖的推特情报抓取与大模型分析核心引擎。
通过纯 Node.js / Playwright 运行时，解决推特官方反爬风控严苛、第三方库易报废的问题，提供面向终端极客的 Headless CLI 管道。

---

## 2. 核心功能规格 (Feature Specs)

### 2.1 运行时与双模调度架构
- **单一运行时**：使用单个 Node.js / Electron 进程与 Playwright 网络流嗅探，严禁拉起双重 Chromium 或调用 Python 脚本；
- **CLI 参数白名单派发**：有参启动命中命令行白名单时直接进入 Headless CLI，stdout 输出标准 JSON，stderr 输出诊断信息；无参启动进入图形界面。

### 2.2 核心采集流水线
- **关注流抓取 (Following)**：基于用户已登录会话向下滚动抓取关注博主推文；
- **全网搜索 (Search)**：支持关键词与推特原生语法（`live`/`top`）；
- **趋势榜单嗅探 (Explore Trends)**：嗅探推特全网热搜话题并分类。

### 2.3 存储与数据模型
- **better-sqlite3 本地持久化**：建立 `tweets.db`，以 `tweet_id` 为唯一主键，支持增量入库去重；
- **原始数据留存**：网络层原始响应快照备份至 `data/raw/` 供调试。

### 2.4 大模型调度引擎 (LLM Core)
- **多厂商抽象**：建立 `BaseLLMProvider`，统一封装 OpenAI、Gemini、DeepSeek、通义千问、智谱、MiniMax、Kimi；
- **全量默认 high 级深度推理**：全模型默认开启长思维链推理；
- **每日早报生成**：基于库内存量推文，按关注流与热点话题输出 Markdown 简报。
