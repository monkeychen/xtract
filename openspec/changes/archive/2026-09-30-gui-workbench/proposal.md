# Proposal

## Why

Xtract 目前已具备生产级 CLI 管道与核心流水线，但在桌面交互侧需要一套「结论先行、信噪比高、开箱即用」的情报内参工作台，一键获取每日推文、捕捉突发热点、提取培训选题与自媒体写作素材，并在离线环境下沉浸式精读与管理 Page Bundle 推文资产。

在实际使用迭代中，早期规划的独立「智能研报」与「趋势雷达」二级 Tab 造成了认知负担与操作割裂。从第一性原理出发，系统果断剥离不可用二级 Tab，全面收敛聚焦于唯一核心视窗——「XTRACT 情报工作台」，并深度补齐视频免落盘按需播放、原生 Markdown 专栏级排版（X Article Executive Summary 卡片）、推文外链还原与短链清洗、严格条数约束与长文默认过滤规则。

## What Changes

本变更实现并优化 Xtract 桌面 GUI 原生界面与工作流，涵盖「1 核心工作台视窗 + 1 常驻设置抽屉」：

- **XTRACT 情报工作台 (StudioView)**：
  - **唯一核心视窗**：彻底剥离不可用二级 Tab，以统一的工作台承载全局推特情报流；
  - **四维数据源极速切换**：时间线关注流（Following）、全网搜索（Search）、博主追踪（User）、X Lists 列表，支持顶部 Chip 瞬间切换；
  - **全网搜索与博主追踪**：输入框默认绝对为空；搜索为空时直接呈现本地全库推文，有关键词时全库模糊检索；博主追踪跨库聚合博主推文；
  - **X Lists 物理分区隔离**：`list_id` 真实落库与强联动过滤，列表互不混淆；
  - **推特日期 ISO-8601 标准化**：严格绝对物理时间倒序排列；
  - **信噪比（SNR）门槛过滤药丸**：`全部` / `50+ 赞` / `200+ 赞` 毫秒级筛选高价值推文；
  - **全流抓取严格数量约束与提前终止**：UI 选择条数（20 / 50 / 100 篇），抓取链路在滚动满足条数时立即早停 break，精准入库；
  - **长推文/专栏文章默认抓取过滤与排版换行自愈**：默认开启深度长文过滤，彻底自愈 `\n\n` 字面量换行；
  - **推特视频在线免落盘流式播放与按需零静默流量**：
    - 主进程自动挂载会话代理（`setProxy`）并动态伪装官方 `Referer: https://x.com/` 突破防盗链；
    - 前端配置 `preload="none"` 实现真正的零静默流量，杜绝未播放先转圈；
    - 配备居中大播放按钮（▶）、错误自愈卡片以及常驻【📋 复制直链】与【🌐 在系统浏览器播放 ↗】；
  - **推文详情原生 Markdown 渲染与 X Article 专栏专属排版**：
    - 采用定制原生 `TweetMarkdown` 引擎，告别粗糙的纯文本 `pre-wrap`；
    - 自动识别 H1-H4 标题与中文节次，将 X Article 专栏的 `> **核心摘要 / 提要**:` 渲染为极具报刊质感的高光速览卡片（⚡）；
    - 正文配图高清展示并支持点击全屏高斯模糊灯箱预览，超链接与 `t.co` 短链语义化还原并支持系统默认浏览器直达；
  - **Master-Detail 双栏与批量操作**：左侧 380px 紧凑推文流，右侧自包含 Page Bundle 深度阅读器，底部浮动批量操作条（`.selbar`）多选导出 Markdown 与级联物理清理。
- **全局偏好设置抽屉 (Settings Drawer)**：
  - 刊头状态指示胶囊（X 会话有效性指示灯、代理状态）；
  - 免 Cookie 原生登录捕获与持久化；
  - 抓取过滤规则开关（默认仅长推文/专栏，可一键放开全部推文）；
  - 7 大主流模型与双轨认证（API Key / 账号订阅免 Key）；
  - 专属套餐端点自动识别（阿里 Token Plan `sk-sp-` / 智谱 Coding Plan）；
  - **模型深度推理开关与强度分级**：开关（ON/OFF）+ 3 级强度（低 Low / 中 Medium / 高 High，默认 ON-High）；
  - 代理穿透与国内模型自动旁路直连。
- **macOS 原生窗口生命周期管理**：
  - 拦截窗口 `close` 事件为 `win.hide()`，监听 `app.on('activate')` 瞬间无感毫秒级唤起并置顶。

## Capabilities

### New Capabilities
- `gui-workbench`: 包含聚焦单一情报工作台的多源情报切换、信噪比筛选、推特视频按需零静默流式播放、原生 Markdown 专栏级排版（Executive Summary 卡片）、全流严格数量约束早停、长文默认过滤、级联物理删除、全局设置抽屉与模型深度推理控制的完整 GUI 交互规范。

## Impact

- **UI / 渲染进程**：新增并精简桌面渲染进程组件，建立独立 `TweetMarkdown.tsx` 原生解析器与 `TweetVideoPlayer` 播放器，严格遵循 Warm Editorial 暖色编辑风格；
- **Preload / IPC 通信**：`window.xtractAPI` 配置契约扩展支持 `reasoningEnabled`、`reasoningEffort` 与完整数据源查询/删除契约；
- **Storage / 持久化层**：支持 `list_id` 物理分区、ISO-8601 标准化日期、`video_url` 动态迁移与真实物理级联删除；
- **Client / 抓取层**：全链路支持 `limit` 提前早停与长推文/专栏文章默认过滤。
